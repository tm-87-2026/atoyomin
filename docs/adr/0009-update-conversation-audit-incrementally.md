# ADR 0009: 公開会話ログの既存レコードを保持して差分追加する

## Status

Proposed

## Context

#30では、保存形式の違いにより全セッションの再変換が止まり、監査ログの更新が停止した。公開用ログのマスクを再変換によって失わず、失敗したセッションを特定できる必要がある。

## Decision

公開ログ内のセッション別件数を追記位置として、今回のセッションの未記録分を追加する。既存レコードは再抽出した内容で置き換えない。未登録の過去セッションだけを取り込み、失敗はセッション別に記録して正常なセッションの更新を続ける。

生記録の前回コピーと今回の抽出結果の先頭を比較し、書き換えがある場合は自動反映せず手動照合を求める。公開ログの置き換えは原子的に行い、更新全体を排他制御する。

## Consequences

公開ログの文面をマスクしても、追記や再実行で元に戻らない。公開ログの行削除やセッションIDの変更は追記位置を壊すため禁止する。原本の形式変更や既存の欠落を件数だけで自動修復することはできず、復元時には個別の照合が必要になる。
