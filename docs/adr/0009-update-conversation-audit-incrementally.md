# ADR 0009: 会話の監査ログは、記録済みの発言を残して追記する

## Status

Proposed

## Context

監査ログは、Codexが会話ごとに保存するファイルから、ユーザーとCodexの発言を取り出して作っている。これまでは保存済みの全ファイルを毎回読み直していたため、未対応の保存形式のファイルが1つあると、後の会話も反映されなくなった（Issue #30）。

また、共有前に監査ログの秘密情報などを伏せ字にしても、元の会話ファイルからログを作り直すと、伏せる前の内容に戻ってしまう。

## Decision

監査ログは全体を作り直さず、記録済みの発言を保持して、未記録の発言だけを追加する。

一部の会話ファイルを読み取れなくても、他の会話の記録は続ける。反映できなかった対象と理由を利用者へ知らせ、元の会話ファイルを使って復旧できるようにする。

## Consequences

記録済みの発言を保持するため、監査ログで伏せ字にした内容が更新によって元に戻ることを防げる。また、一部のファイルの問題で更新全体が止まらなくなる。

一方、記録済みの内容に欠落や誤りがあっても、通常の更新では修復しない。元の会話ファイルと監査ログを照合する復旧作業が必要になる。
