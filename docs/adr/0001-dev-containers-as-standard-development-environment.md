# ADR 0001: Dev Containersを標準開発環境にする

## Status

Accepted — 2026-10-21

## Context

あとよみんの開発メンバーはWindows（WSL2）とmacOSを利用する。必要な開発ツールを各OSに直接導入すると、バージョン差異や導入手順のずれにより、開発環境を再現しにくい。

チーム全員が同じ開発ツールとバージョンを利用し、リポジトリから開発環境を再構築できる必要がある。

検討した選択肢は次のとおりである。

- **Dev Containersを標準開発環境にする**：Dev Containers（開発に必要なツールをDockerコンテナへまとめ、エディタから開く仕組み）の設定をリポジトリで管理する。必要なツールはコンテナ内に導入する。
- **各自のホストOSに直接ツールを導入する**：READMEの手順に従い、各自が必要なツールを導入・更新する。

## Decision

Dev Containersを、あとよみんの標準開発環境とする。開発環境の定義は`.devcontainer/`で管理し、アプリケーション開発に必要なツールは原則としてコンテナ内で提供する。

## Consequences

- OS差異をコンテナに閉じ込め、チームで再現性の高い開発環境を共有できる。
- 環境定義とその変更をリポジトリで管理できる。
- 開発にはDocker互換ランタイムとDev Containers対応エディタが必要になる。
